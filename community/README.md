# Community picks

Public Grok Bot templates by other creators that have a clear job and show the habits this library looks for. Each card credits its author and links the listing and the Add to Grok Bot page.

We never copy another creator's instructions. A card says what the template does in the creator's own words, why we think it is gold, and what anyone can see from outside: the skills, integrations and routines its public page lists. That is the level **assayed from the page**. We cannot read the instructions, so no community pick is marked gold here.

A public repository is read at one full commit. That card names each seat in our own words, keeps quotes short, and cites what each seat may send, publish, spend, or merge from the files at that commit, including the license. The [rubric](../RUBRIC.md) sets the level from that read. An open fracture or break, such as a commit that marks the repository superseded while the quick start still installs it, is **watch**. Gold still waits on a live eval recorded in this library.

The first ten pages were read on 2026-09-30 and the next six on 2026-10-01, from the [Grok Bot Marketplace](https://x.ai/bot/marketplace); each card gives its own date. The [listing mine](../pantry/2026-10-01-listing-mine.md) shows every listing and which ones are carded. Every listing's page data shows an install count of 0, so we do not read that field as a count.
