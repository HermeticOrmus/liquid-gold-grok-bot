# Routines: Sample

## Sample event

| Field | Setting |
|-------|---------|
| Owning bot | Sample |
| Trigger | Event: a notification for one sample repo |
| Schedule and time zone | None when the event trigger is available. A cron you choose, in the owner's time zone, when it is not. |
| Input | The sample notification |
| Result | One note when something changed. Nothing when nothing changed. |
| Approval boundary | Never sends, posts, or spends. |
| Missing source | If the notification cannot be read, say so and stop. |
