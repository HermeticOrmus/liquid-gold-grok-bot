# Plugins: Gardener

| Plugin | Why | Access it needs |
|--------|-----|-----------------|
| GitHub (first-party) | Clone, push a `garden/` branch, open a pull request, read CI. | Write to branches; merge stays behind Ask first. |

## Ask first rules

Add these in **Settings, General, Auto-review**:

- Ask first before merging a pull request.
- Ask first before pushing to the default branch.
- Ask first before deleting a branch.
