# Plugins: Playbook Keeper

| Plugin | Why | Access it needs |
|--------|-----|-----------------|
| GitHub (optional) | Open a pull request when the fix is a check or a doc in a repo. | Write to branches; merge stays behind Ask first. |

Everything else happens in Grok Bot: it reads conversations it is part of, and bots can hand it work by direct message.

## Ask first rules

Add these in **Settings, General, Auto-review**:

- Ask first before merging a pull request.
- Ask first before creating an issue or ticket.
