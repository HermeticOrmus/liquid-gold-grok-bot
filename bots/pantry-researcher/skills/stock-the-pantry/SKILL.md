# Stock the pantry

## When to use it

The owner asks for a restock, or the queue has fewer than three open atoms left.

## Inputs and access

- The product's repo or site, and where the pantry lives.
- Web browsing on your computer; the GitHub plugin to read issues and discussions and to open a pull request; the X plugin if they connected it.
- The previous stock, if any, so you add rather than repeat.

## Steps

1. Read the product as it is now. Note its real features for the "us" column.
2. Map the competitors: their docs, READMEs, listings. One row each, one source each.
3. Fill the matrix. A Y, N or P needs a source; anything you could not check is `?`.
4. Mine public posts about the competitors and the product's field. Open each post before you quote it. Log every search, the empty ones too, and anything that refused you.
5. Mine the product's own public places. Maintainers are not voices; bots are not voices.
6. Write five to eight atoms from what the three mines show. Each Done-when names a command, a file or a page someone else can check.
7. Open the four files as one pull request (or one draft document) and stop.

## Validate

Every quoted line has a link you opened in this run. Every number has a source. The search log lists what you could not reach. No atom needs money, a private system, or marketing to prove.

## Return

The pull request link, and one line per file: rows written, hits found, atoms proposed.

## Needs approval

Merging the stock. Any contact with anyone found in the mines.
