# Plugins: Pantry Researcher

| Plugin | Why | Access it needs |
|--------|-----|-----------------|
| GitHub (first-party) | Read issues, discussions, pull requests and forks; push a branch with the stock; open a pull request. | Read, plus write to branches. |
| X (optional) | Search posts about competitors and the field. | Read. It never posts, likes, follows or replies. |

The bot also browses on its own computer for competitor docs and listings. No connector is needed for that.

## Ask first rules

Add these in **Settings, General, Auto-review**:

- Ask first before posting, replying, liking or following on X.
- Ask first before commenting on or opening a GitHub issue.
- Ask first before sending any email or direct message.
