# Plugins: Desk

| Plugin | Why | Access it needs |
|--------|-----|-----------------|
| GitHub (first-party) | Read the Goal, push a branch, open and merge the pull request, read CI. | Write to branches and pull requests; merge stays behind Ask first. |
| Cursor cloud agents (if your plan has them) | For a Goal bigger than the bot's own computer. | Launch agents, only after "Yes launch it". |

## Ask first rules

Add these in **Settings, General, Auto-review**:

- Ask first before merging a pull request.
- Ask first before pushing to the default branch.
- Ask first before launching a cloud agent.
- Ask first before commenting on an issue or pull request.
