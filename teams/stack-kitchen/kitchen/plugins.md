# Plugins: Kitchen

| Plugin | Why | Access it needs |
|--------|-----|-----------------|
| GitHub (first-party) | Read Goals, labels, pull requests and CI; set `up-next` on the next Goal when the owner picks it. | Read, plus labels. No merge, no push. |

## Ask first rules

Add these in **Settings, General, Auto-review**:

- Ask first before merging a pull request.
- Ask first before pushing any commit.
- Ask first before commenting on an issue or pull request.
